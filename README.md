# Portfolio de Tomas Cano Nieto

Portfolio personal de Tomas Cano Nieto, desarrollador web y especialista en automatizacion con IA.

## Estructura

- `index.html`: pagina principal del portfolio.
- `assets/`: logotipo e imagenes visuales.
- `css/`: estilos base y estilos complementarios.
- `js/`: interacciones, filtros, modales y animaciones.
- `docs/`: CV y documentacion de proyectos.

## Uso local

Abre `index.html` directamente en el navegador. No necesita servidor para la version estatica.

## Contenido

El portfolio incluye experiencia laboral, formacion DAW y SMR, stack tecnologico, 14 proyectos, enlaces a GitHub, demos, CV descargable y contacto.
